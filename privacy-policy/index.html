Privacy Policy

What this site collects, what it doesn't, and why.

The short version

This site uses exactly one cookie, and only if you turn it on yourself. There's no analytics, no third-party trackers, and nothing about you is ever sent anywhere or shown to Dr. Paul.

The one cookie this site uses

This cookie exists for a single feature: an optional “path tracker” — a countdown widget that follows you around the site if you opt in, tracking which pages you've visited during that one session.

  • What it is: a first-party cookie, set directly by paulmress.com — not by any outside company.
  • What it contains: the list of pages you've visited since you turned the feature on, and an expiration timestamp. That's the entire contents.
  • What it does NOT contain: no name, no email address, no IP address, no device ID — nothing that identifies you.
  • Where it goes: nowhere. It is never transmitted to a server, never logged, and never visible to Dr. Paul or anyone else. It lives only in your own browser.
  • How long it lasts: 15 minutes from the moment you turn the feature on. Then it self-destructs automatically — Mission-Impossible style — with no renewal and no re-prompt.
  • How to end it early: dismiss the countdown widget at any point and the cookie is deleted immediately, before the 15 minutes are up.
  • Opt-in only: this cookie is never set by default, and never set just by visiting the site. It only exists if you actively turn the feature on.

No third-party cookies, no analytics, no ad trackers

Outside of that one opt-in cookie, this site sets no other cookies of any kind. There's no Google Analytics, no advertising network, no social media pixel, and no third-party tracking script anywhere on paulmress.com.

What “no third-party cookies” doesn't mean

Saying there are no third-party cookies is specific and true — but it isn't the same as saying no other service touches this site anywhere. Two pieces of ordinary web infrastructure are part of how paulmress.com runs, and each may keep its own basic access logs, separate from anything above:

  • Google Fonts. The typefaces on this site load from Google's font CDN. Like any web request, that request can be seen by Google as part of normal delivery (e.g., an IP address and a timestamp) — paulmress.com doesn't control or receive that data.
  • GitHub Pages. This site is hosted on GitHub Pages, which may keep standard infrastructure-level server logs — the kind most web hosts keep — unrelated to the path-tracker feature described above.

Neither of these is a cookie, neither is used to track or profile you, and paulmress.com has no access to or control over either — they're simply part of how any website reaches a browser.

Changes to this policy

If this policy changes, the update will be posted here with a new “Last updated” date. Continuing to use the site after a change means you accept the update.
